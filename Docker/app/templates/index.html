How it Works

    
Passwords are generated locally in your browser — nothing is sent to a server.

    
    
      
  • 4 words: adjective, noun, verb, noun.
    • 
      
  • First letter of each word is capitalized → mixes uppercase and lowercase.
    • 
      
  • Compute base number from first letters (A=1 … Z=26): base = sum of first letters
    • 
      
  • Compute numbers from base:
        
      
          
    • 2-digit: NN = base % 100
      • 
          
    • 4-digit PIN: PIN4 = (base × 137) % 10000
      • 
          
    • 6-digit PIN: PIN6 = (base × 137 × 53) % 1000000
      • 
        
    
      
    • 
      
  • Password versions:
        
      
          
    • Long mnemonic: words separated by dashes + 2-digit number
      • 
          
    • Bank-accepted (short): first 2 letters of each word + exclamation + 2-digit number (complies with bank rules: uppercase, lowercase, symbol, number)
